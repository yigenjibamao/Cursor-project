# 奶茶与年轻人 · 文化观察项目

一个介绍奶茶对当代年轻人影响的静态网页项目，涵盖社交、消费、健康与文化等多个维度。

## 项目简介

本项目通过单页网站的形式，探讨奶茶如何从一杯普通饮品演变为年轻人生活方式的重要组成部分。内容包括：

- **概览** — 奶茶流行的原因（低门槛、社交货币、个性化、即时满足）
- **社交影响** — 破冰工具、群体认同、线上传播、情感寄托
- **消费习惯** — 消费频次数据可视化、消费心理分析
- **健康考量** — 糖分与咖啡因风险、理性消费趋势
- **文化符号** — 新茶饮时代、颜值经济、文化出海、亚文化载体
- **互动测试** — 「奶茶人格」小测验

## 技术栈

- **HTML5** — 语义化结构
- **CSS3** — Flexbox / Grid 布局、CSS 变量、响应式设计
- **JavaScript (ES6+)** — Intersection Observer 滚动动画、计数器、互动测验
- **Google Fonts** — Noto Sans SC 中文字体

## 快速开始

无需构建工具或依赖安装，直接用浏览器打开即可：

```bash
# 方式一：直接打开
open index.html

# 方式二：使用本地服务器（推荐，避免部分浏览器跨域限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
